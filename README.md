# University Course Registration System

A Python-based university course registration system with waiting list management and fee calculation.

## Libraries Required

| Library | Type | Purpose |
|--------|------|---------|
| `abc`  | Built-in (no install needed) | Used for Abstract Base Classes |

## How to Run

Make sure you have **Python 3.x** installed, then run:
```bash
python test.py
```

## Features

- Register students to courses
- Auto waiting list when seats are full
- Fee discount for final year and merit students
- Drop course and auto-promote from waiting list
- Search registrations by ID or course code
- View total revenue and occupancy report
